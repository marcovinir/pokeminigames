# Pokédex Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Páginas públicas `/pokedex` (tarjetas con buscador y filtros) y `/pokedex/:id` (ficha completa), con enlace en el encabezado (issue #27).

**Architecture:** Un script genera `server/data/pokedex.snapshot.json` desde PokeAPI con funciones puras probadas. El servidor lo carga al arrancar y lo sirve de solo lectura, sin base de datos. El cliente filtra en memoria y guarda los filtros en la dirección. El catálogo del juego no se toca.

**Tech Stack:** TypeScript, Express 5, React 19, React Router 8, Tailwind 4, vitest + RTL + supertest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-30-pokedex-design.md`

## Global Constraints

- Rama `feat/pokedex`; entra en `main` por PR, y fusionar necesita el permiso de Marco.
- Español con tildes en pantallas y commits; identificadores en inglés. TDD: cada prueba se ve fallar antes del código.
- Sin dependencias nuevas, sin migraciones. `catalog.snapshot.json`, `/pokemon/names` y las partidas no cambian.
- Solo las 1025 especies, cada una con su forma base. Fuera: movimientos, ubicaciones, crianza, entrenamiento y formas.
- Texto que falta en español: se muestra el inglés con «(en inglés)»; si tampoco hay, se omite. Nunca traducción automática.
- Crédito exacto bajo lore y habilidades: «Textos oficiales de los juegos de Pokémon, © Nintendo / Game Freak / Creatures. Datos vía PokeAPI.»
- 60 tarjetas por tanda; imágenes con `loading="lazy"`.
- Parámetros de la dirección: `tipo1`, `tipo2`, `gen`, `orden`, `q`, `ver`; lo desconocido se ignora sin romper.
- Colores solo de tokens del tema (auditoría de contraste vacía en los 4 temas/modos).

## Desviación de la spec (ruling)

La spec pide `GET /pokedex` y `GET /pokedex/:id` en la API, pero el servidor sirve API y cliente desde un solo origen: esas rutas chocarían con las páginas `/pokedex` al recargar. **Se usan `GET /pokemon/dex` y `GET /pokemon/dex/:id`**, bajo el prefijo `/pokemon`, que ya tiene proxy de desarrollo y límite de peticiones.

## Decisión pendiente de Marco

Con dos enlaces, el encabezado casi seguro no cabe a 360 px en Pokédex sin sesión (ya está al límite). Propuesta: **que el logo muestre solo la bola por debajo de `sm` también sin sesión**. La Task 5 no se cierra sin esa decisión.

## Review Focus

1. Pokémon sin evolución, con ramas (Eevee, 8 ramas) y con varias etapas ramificadas: la cadena se ve completa desde cualquier miembro. Pruebas en las Tasks 1 y 4.
2. Volver de una ficha a la lista: conserva filtros, tandas cargadas y posición. Prueba en la Task 3.
3. Fallo de red al pedir la lista o la ficha: aviso con «Reintentar», nunca «no existe». Pruebas en las Tasks 3 y 4.
4. `/pokedex/0`, `/pokedex/1026`, `/pokedex/abc`, `/pokedex/6.5`: «Ese Pokémon no existe». Pruebas en las Tasks 2 y 4.
5. Nombres largos y descripciones largas a 360 px: nada ensancha la página. Prueba en la Task 6.

```ts
export type LocalizedLanguage = "es" | "en";
export interface LocalizedText { text: string; language: LocalizedLanguage }
export type EvolutionCondition =
  | { kind: "level"; level: number; timeOfDay?: "day" | "night" }
  | { kind: "item"; item: string }
  | { kind: "trade" }
  | { kind: "friendship"; timeOfDay?: "day" | "night" }
  | { kind: "other" };
export interface EvolutionNode { id: number; name: string; condition: EvolutionCondition | null; next: EvolutionNode[] }
export interface PokedexAbility { name: string; hidden: boolean; description: LocalizedText | null }
export interface PokedexEntry { id: number; names: { es: string; en: string }; types: TypeName[]; total: number; generation: number; spriteUrl: string }
export interface PokedexDetail extends PokedexEntry { stats: BaseStats; abilities: PokedexAbility[]; lore: (LocalizedText & { game: string }) | null; evolution: EvolutionNode }
```

- Produces en `server/src/catalog/pokedex-snapshot.ts`: `latestLocalized(entries)`, `toEvolutionCondition(details)`, `toEvolutionNode(link, lookups)`, `toPokedexDetail(pokemon, species, lookups)`, `fetchPokedex({ fetchJson, onProgress })`. `lookups` resuelve nombres de especie, habilidad, objeto y juego ya descargados.
