# Pokémon Minigames — Etapa 1: Base Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar listo el servidor base: monorepo, autenticación con JWT, esquema completo de base de datos y el catálogo de 1025 Pokémon (nombres en español e inglés) cargado desde un snapshot versionado.

**Architecture:** Monorepo npm con un paquete `server/` (Express 5 + Prisma 7 + PostgreSQL). Las dependencias se inyectan por constructor (`AuthService`, `createApp`) para poder probarlas con un reloj falso y una base de datos real. El catálogo se descarga una sola vez de PokéAPI a un JSON commiteado; el seed y el despliegue nunca dependen de PokéAPI.

**Tech Stack:** Node 24, TypeScript 7, Express 5, Prisma 7.10.0 (`@prisma/adapter-pg`), PostgreSQL 18, Zod 4, bcryptjs, jsonwebtoken, Vitest 5, Supertest.

**Spec:** `docs/superpowers/specs/2026-09-30-pokemon-minigames-design.md` (este plan implementa la etapa 1 de la sección 9).

## Global Constraints

- Stack del servidor: "Node + TypeScript, Express, Socket.io, PostgreSQL + Prisma" (Socket.io entra en la etapa 2).
- Modelo de datos en tercera forma normal: "sin JSONB para equipos ni tipos".
- Access token JWT de 1 h, enviado como `Authorization: Bearer`.
- Refresh token de 7 días en cookie `httpOnly`, guardado como hash en `refresh_tokens`.
- "Durante las partidas no se llama a PokéAPI": el catálogo sale del snapshot `server/data/catalog.snapshot.json`.
- Nombres de Pokémon en español e inglés, ambos válidos, sin distinguir tildes ni mayúsculas.
- Los 18 tipos: normal, fighting, flying, poison, ground, rock, bug, ghost, steel, fire, water, grass, electric, psychic, ice, dragon, dark, fairy (sin `stellar` ni `unknown`).
- Configuración únicamente por variables de entorno, sin depender de un proveedor.
- Mensajes de error al usuario en español; identificadores de código en inglés.
- Se sigue TDD: cada comportamiento se prueba antes de implementarlo.
- Versiones: `prisma`, `@prisma/client` y `@prisma/adapter-pg` fijadas en **7.10.0** exacta. El `latest` del paquete `prisma` en npm es un RC de la 8: no ejecutes `npm i prisma@latest` ni `npm audit fix --force` (este último bajaría Prisma a la 6).

## Review Focus

Entradas y condiciones que la spec no menciona pero que muerden a una persona real; cada una tiene su prueba en la tarea indicada.

1. **Contraseñas con caracteres no ASCII o de más de 72 bytes.** bcrypt solo mira los primeros 72 bytes: "ñ" × 37 son 74 bytes y dos contraseñas distintas darían el mismo hash. Se rechazan con 400; las de hasta 72 bytes con tildes y emoji funcionan. → Task 10 (`auth.schemas.test.ts`) y Task 11 (`auth.routes.test.ts`).
2. **Operaciones simultáneas.** Seis registros con el mismo email a la vez dejan un solo usuario y los demás reciben `EMAIL_TAKEN` (no un 500); ocho refrescos con el mismo token dejan solo una sesión ganadora. → Task 10 (`auth.service.test.ts`).
3. **Access tokens manipulados.** Token sin firma (`alg: none`), firmado con otro algoritmo (HS512), con el payload cambiado, expirado o que no es un JWT: todos dan 401, nunca 500. → Task 9 (`tokens.test.ts`) y Task 11.
4. **Nombres de Pokémon con signos.** "Nidoran♀/♂", "Mr. Mime", "Farfetch'd", "Flabébé", "Ho-Oh", "Type: Null": deben encontrarse escribiéndolos con o sin tildes, guiones o espacios, y dos Pokémon nunca pueden compartir el mismo nombre normalizado. → Task 3 y Task 4 (`validateSnapshot`), Task 7 (datos reales).
5. **Resembrar y restricciones de la base de datos.** Volver a ejecutar el seed con datos cambiados actualiza sin duplicar ni borrar Pokémon; y la base de datos rechaza por sí misma partidas con configuración imposible, pares de tipos desordenados, una segunda respuesta del mismo jugador en una ronda y `total_stats` incoherentes. → Task 2 (`schema.test.ts`) y Task 6 (`seed.test.ts`).

- [ ] **Step 6: Implementar `loadEnv`**

`server/src/config/env.ts`:

```ts
import { z } from "zod";

const envSchema = z
  .object({
    NODE_ENV: z.enum(["development", "test", "production"]).default("development"),
    PORT: z.coerce.number().int().min(1).max(65535).default(3000),
    DATABASE_URL: z.string().min(1, "es obligatoria"),
    JWT_ACCESS_SECRET: z.string().min(32, "debe tener al menos 32 caracteres"),
    ACCESS_TOKEN_TTL_SECONDS: z.coerce.number().int().positive().default(3600),
    REFRESH_TOKEN_TTL_DAYS: z.coerce.number().int().positive().default(7),
    BCRYPT_COST: z.coerce.number().int().min(4).max(15).default(12),
    CORS_ORIGIN: z.string().min(1).default("http://localhost:5173"),
    COOKIE_SECURE: z
      .enum(["true", "false"])
      .default("false")
      .transform((value) => value === "true"),
    COOKIE_SAME_SITE: z.enum(["lax", "strict", "none"]).default("lax"),
  })
  .refine((env) => env.COOKIE_SAME_SITE !== "none" || env.COOKIE_SECURE, {
    message: "COOKIE_SAME_SITE=none exige COOKIE_SECURE=true",
    path: ["COOKIE_SAME_SITE"],
  });

export type Env = z.infer<typeof envSchema>;

export function loadEnv(source: Record<string, string | undefined> = process.env): Env {
  const result = envSchema.safeParse(source);
  if (!result.success) {
    const details = result.error.issues
      .map((issue) => `  - ${issue.path.join(".")}: ${issue.message}`)
      .join("\n");
    throw new Error(`Variables de entorno inválidas:\n${details}`);
  }
  return result.data;
}
```

`server/test/helpers/db.ts`:

```ts
import { createPrismaClient } from "../../src/db/prisma.js";

export const prisma = createPrismaClient(process.env.DATABASE_URL!);

/** Vacía las tablas mutables. El catálogo (tipos, Pokémon) se conserva. */
export async function resetDatabase(): Promise<void> {
  await prisma.$executeRawUnsafe(
    'TRUNCATE TABLE "round_picks", "rounds", "game_players", "games", "refresh_tokens", "users" CASCADE',
  );
}

/**
 * Abre varias conexiones del pool antes de una prueba de concurrencia. Sin esto, las
 * peticiones esperan a que se abran las conexiones y terminan ejecutándose casi en serie,
 * con lo que la carrera que se quiere probar nunca ocurre.
 */
export async function warmUpPool(connections = 8): Promise<void> {
  await Promise.all(
    Array.from({ length: connections }, () => prisma.$queryRaw`SELECT 1 AS ok FROM pg_sleep(0.2)`),
  );
}

/** Vacía también el catálogo. Solo para las pruebas del seed. */
export async function resetCatalog(): Promise<void> {
  await resetDatabase();
  await prisma.$executeRawUnsafe(
    'TRUNCATE TABLE "pokemon_names", "pokemon_types", "pokemon", "types" CASCADE',
  );
}
```

```ts
/**
 * Forma canónica para comparar nombres de Pokémon: minúsculas, sin tildes y sin signos.
 * "Nidoran♀" → "nidoranf", "Mr. Mime" → "mrmime", "Flabébé" → "flabebe".
 */
export function normalizeName(input: string): string {
  return input
    .normalize("NFD")
    .replace(/\p{M}/gu, "")
    .toLowerCase()
    .replaceAll("♀", "f")
    .replaceAll("♂", "m")
    .replace(/[^a-z0-9]/g, "");
}
```

```ts
  "grass",
  "electric",
  "psychic",
  "ice",
  "dragon",
  "dark",
  "fairy",
] as const;

export type TypeName = (typeof TYPE_NAMES)[number];

export interface BaseStats {
  hp: number;
  attack: number;
  defense: number;
  spAttack: number;
  spDefense: number;
  speed: number;
}

export interface PokemonSnapshot {
  /** Número de la Pokédex nacional. */
  id: number;
  /** Uno o dos tipos, en el orden de los slots de PokéAPI. */
  types: TypeName[];
  stats: BaseStats;
  spriteUrl: string;
  names: { es: string; en: string };
}

export interface CatalogSnapshot {
  generatedAt: string;
  source: string;
  pokemon: PokemonSnapshot[];
}

export function totalStats(stats: BaseStats): number {
  return stats.hp + stats.attack + stats.defense + stats.spAttack + stats.spDefense + stats.speed;
}

export function typeId(name: TypeName): number {
  return TYPE_NAMES.indexOf(name) + 1;
}

/** Devuelve la lista de problemas del snapshot; vacía si es válido. */
export function validateSnapshot(snapshot: CatalogSnapshot): string[] {
  const problems: string[] = [];
  if (snapshot.pokemon.length === 0) {
    return ["El snapshot no tiene Pokémon"];
  }

  const seenIds = new Set<number>();
  const idsByName = new Map<string, Set<number>>();

  for (const p of snapshot.pokemon) {
    const label = `#${p.id}`;
    if (!Number.isInteger(p.id) || p.id < 1) problems.push(`${label}: id inválido`);
    if (seenIds.has(p.id)) problems.push(`${label}: id repetido`);
    seenIds.add(p.id);

    if (p.types.length < 1 || p.types.length > 2) problems.push(`${label}: debe tener 1 o 2 tipos`);
    for (const type of p.types) {
      if (!(TYPE_NAMES as readonly string[]).includes(type)) problems.push(`${label}: tipo desconocido "${type}"`);
    }
    if (new Set(p.types).size !== p.types.length) problems.push(`${label}: tipos repetidos`);

    for (const [stat, value] of Object.entries(p.stats)) {
      if (!Number.isInteger(value) || value < 1) problems.push(`${label}: stat ${stat} inválida (${value})`);
    }
    if (!p.spriteUrl) problems.push(`${label}: sin sprite`);

    for (const language of ["es", "en"] as const) {
      const name = p.names[language];
      const normalized = name ? normalizeName(name) : "";
      if (!normalized) {
        problems.push(`${label}: nombre ${language} vacío`);
        continue;
      }
      const ids = idsByName.get(normalized) ?? new Set<number>();
      ids.add(p.id);
      idsByName.set(normalized, ids);
    }
  }

  for (const [name, ids] of idsByName) {
    if (ids.size > 1) problems.push(`El nombre normalizado "${name}" es ambiguo: Pokémon ${[...ids].map((i) => `#${i}`).join(", ")}`);
  }
  return problems;
}
```

```ts
import {
  type BaseStats,
  type CatalogSnapshot,
  type PokemonSnapshot,
  TYPE_NAMES,
  type TypeName,
} from "./snapshot.js";

export const POKEAPI_BASE_URL = "https://pokeapi.co/api/v2";

/** Solo los campos de la respuesta de PokéAPI que usamos. */
export interface PokeApiPokemon {
  id: number;
  name: string;
  types: { slot: number; type: { name: string } }[];
  stats: { base_stat: number; stat: { name: string } }[];
  sprites: { front_default: string | null };
}

export interface PokeApiSpecies {
  names: { language: { name: string }; name: string }[];
}

const STAT_KEYS: Record<string, keyof BaseStats> = {
  hp: "hp",
  attack: "attack",
  defense: "defense",
  "special-attack": "spAttack",
  "special-defense": "spDefense",
  speed: "speed",
};

function spriteFallback(id: number): string {
  return `https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/${id}.png`;
}

export function toPokemonSnapshot(pokemon: PokeApiPokemon, species: PokeApiSpecies): PokemonSnapshot {
  const types = [...pokemon.types]
    .sort((a, b) => a.slot - b.slot)
    .map((entry) => {
      const name = entry.type.name;
      if (!(TYPE_NAMES as readonly string[]).includes(name)) {
        throw new Error(`Pokémon #${pokemon.id}: tipo desconocido "${name}"`);
      }
      return name as TypeName;
    });

  const stats = {} as BaseStats;
  for (const entry of pokemon.stats) {
    const key = STAT_KEYS[entry.stat.name];
    if (key) stats[key] = entry.base_stat;
  }
  for (const key of Object.values(STAT_KEYS)) {
    if (typeof stats[key] !== "number") throw new Error(`Pokémon #${pokemon.id}: falta la stat ${key}`);
  }

  const nameIn = (language: string) => species.names.find((n) => n.language.name === language)?.name;
  const en = nameIn("en");
  if (!en) throw new Error(`Pokémon #${pokemon.id}: no tiene nombre en inglés`);

  return {
    id: pokemon.id,
    types,
    stats,
    spriteUrl: pokemon.sprites.front_default ?? spriteFallback(pokemon.id),
    // Si PokéAPI aún no tiene el nombre en español, se usa el inglés.
    names: { es: nameIn("es") ?? en, en },
  };
}

export type FetchJson = (path: string) => Promise<unknown>;

export interface FetchCatalogOptions {
  fetchJson: FetchJson;
  concurrency?: number;
  onProgress?: (done: number, total: number) => void;
}

/** Descarga todas las especies y arma el snapshot. Falla ante el primer error. */
export async function fetchCatalog({
  fetchJson,
  concurrency = 8,
  onProgress,
}: FetchCatalogOptions): Promise<CatalogSnapshot> {
  const { count } = (await fetchJson("pokemon-species?limit=1")) as { count: number };
  const results: PokemonSnapshot[] = new Array<PokemonSnapshot>(count);
  let next = 0;
  let done = 0;
  let failed = false;

  async function worker(): Promise<void> {
    while (!failed && next < count) {
      const id = ++next;
      try {
        const [pokemon, species] = await Promise.all([fetchJson(`pokemon/${id}`), fetchJson(`pokemon-species/${id}`)]);
        results[id - 1] = toPokemonSnapshot(pokemon as PokeApiPokemon, species as PokeApiSpecies);
      } catch (error) {
        failed = true;
        throw error;
      }
      onProgress?.(++done, count);
    }
  }

  await Promise.all(Array.from({ length: Math.min(concurrency, count) }, worker));

  return { generatedAt: new Date().toISOString(), source: POKEAPI_BASE_URL, pokemon: results };
}
```

```ts
import { POKEAPI_BASE_URL, fetchCatalog } from "../src/catalog/pokeapi.js";
import { validateSnapshot } from "../src/catalog/snapshot.js";

const MAX_ATTEMPTS = 4;

async function fetchJson(path: string): Promise<unknown> {
  for (let attempt = 1; attempt <= MAX_ATTEMPTS; attempt++) {
    try {
      const response = await fetch(`${POKEAPI_BASE_URL}/${path}`);
      if (response.ok) return await response.json();
      // Un 404 no se arregla reintentando.
      if (response.status === 404) throw new Error(`404 ${path}`);
      throw new Error(`HTTP ${response.status} en ${path}`);
    } catch (error) {
      const permanent = error instanceof Error && error.message.startsWith("404");
      if (permanent || attempt === MAX_ATTEMPTS) throw error;
      await new Promise((resolve) => setTimeout(resolve, 500 * attempt));
    }
  }
  throw new Error("inalcanzable");
}
```

```ts
import type { PrismaClient } from "../db/prisma.js";
import { normalizeName } from "./normalize.js";
import { type CatalogSnapshot, TYPE_NAMES, totalStats, typeId, validateSnapshot } from "./snapshot.js";

/**
 * Carga el catálogo en la base de datos. Es idempotente: se puede ejecutar de nuevo
 * con un snapshot actualizado y deja los datos al día. Los Pokémon nunca se borran
 * porque las partidas guardadas los referencian.
 */
export async function seedCatalog(prisma: PrismaClient, snapshot: CatalogSnapshot): Promise<{ pokemon: number }> {
  const problems = validateSnapshot(snapshot);
  if (problems.length > 0) {
    throw new Error(`Snapshot inválido:\n${problems.map((p) => `  - ${p}`).join("\n")}`);
  }

  const pokemonRows = snapshot.pokemon.map((p) => ({
    id: p.id,
    baseHp: p.stats.hp,
    baseAttack: p.stats.attack,
    baseDefense: p.stats.defense,
    baseSpAttack: p.stats.spAttack,
    baseSpDefense: p.stats.spDefense,
    baseSpeed: p.stats.speed,
    totalStats: totalStats(p.stats),
    spriteUrl: p.spriteUrl,
  }));

  // Una sola transacción: o queda todo cargado o no cambia nada.
  await prisma.$transaction([
    prisma.pokemonName.deleteMany(),
    prisma.pokemonType.deleteMany(),
    ...TYPE_NAMES.map((name, index) =>
      prisma.type.upsert({ where: { id: index + 1 }, create: { id: index + 1, name }, update: { name } }),
    ),
    ...pokemonRows.map(({ id, ...data }) =>
      prisma.pokemon.upsert({ where: { id }, create: { id, ...data }, update: data }),
    ),
    prisma.pokemonType.createMany({
      data: snapshot.pokemon.flatMap((p) =>
        p.types.map((type, index) => ({ pokemonId: p.id, typeId: typeId(type), slot: index + 1 })),
      ),
    }),
    prisma.pokemonName.createMany({
      data: snapshot.pokemon.flatMap((p) => [
        { pokemonId: p.id, language: "es" as const, name: p.names.es, normalizedName: normalizeName(p.names.es) },
        { pokemonId: p.id, language: "en" as const, name: p.names.en, normalizedName: normalizeName(p.names.en) },
      ]),
    }),
  ]);

  return { pokemon: snapshot.pokemon.length };
}
```

```ts
import type { ErrorRequestHandler, RequestHandler } from "express";
import { ZodError } from "zod";

export type ErrorCode =
  | "VALIDATION_ERROR"
  | "EMAIL_TAKEN"
  | "USERNAME_TAKEN"
  | "INVALID_CREDENTIALS"
  | "UNAUTHORIZED"
  | "INVALID_REFRESH_TOKEN"
  | "NOT_FOUND"
  | "INTERNAL_ERROR";

/** Error esperado de la aplicación: se convierte en una respuesta HTTP con código tipado. */
export class AppError extends Error {
  constructor(
    readonly status: number,
    readonly code: ErrorCode,
    message: string,
    readonly details?: unknown,
  ) {
    super(message);
    this.name = "AppError";
  }
}

export const notFoundHandler: RequestHandler = (_req, res) => {
  res.status(404).json({ error: { code: "NOT_FOUND", message: "Ruta no encontrada" } });
};

function errorType(err: unknown): unknown {
  return typeof err === "object" && err !== null ? (err as { type?: unknown }).type : undefined;
}

// Express identifica un manejador de errores por tener 4 parámetros.
export const errorHandler: ErrorRequestHandler = (err, _req, res, _next) => {
  if (err instanceof AppError) {
    res.status(err.status).json({
      error: { code: err.code, message: err.message, ...(err.details ? { details: err.details } : {}) },
    });
    return;
  }
  if (err instanceof ZodError) {
    res.status(400).json({
      error: {
        code: "VALIDATION_ERROR",
        message: "Datos inválidos",
        details: err.issues.map((issue) => ({ path: issue.path.join("."), message: issue.message })),
      },
    });
    return;
  }
  if (errorType(err) === "entity.parse.failed") {
    res.status(400).json({ error: { code: "VALIDATION_ERROR", message: "El cuerpo no es JSON válido" } });
    return;
  }
  if (errorType(err) === "entity.too.large") {
    res.status(413).json({ error: { code: "VALIDATION_ERROR", message: "El cuerpo es demasiado grande" } });
    return;
  }
  console.error(err);
  res.status(500).json({ error: { code: "INTERNAL_ERROR", message: "Error interno del servidor" } });
};
```

```ts
export interface PasswordHasher {
  hash(plain: string): Promise<string>;
  verify(plain: string, hash: string): Promise<boolean>;
}

/** bcrypt solo considera los primeros 72 bytes; el registro rechaza contraseñas más largas. */

export function createPasswordHasher(cost: number): PasswordHasher {

    verify: (plain, hash) => bcrypt.compare(plain, hash),
```

```ts
import { createHash, randomBytes } from "node:crypto";
import jwt from "jsonwebtoken";
import { AppError } from "../http/errors.js";

export interface AccessTokenPayload {
  /** Id del usuario. */
  sub: string;
  username: string;
}

export interface TokenService {
  signAccessToken(payload: AccessTokenPayload): string;
  /** Lanza AppError(401, "UNAUTHORIZED") si el token es inválido, está manipulado o expiró. */
  verifyAccessToken(token: string): AccessTokenPayload;
  /** Token opaco aleatorio para la cookie de refresco. */
  generateRefreshToken(): string;
  /** Hash con el que se guarda el refresh token en la base de datos. */
  hashRefreshToken(token: string): string;
}

export interface TokenServiceOptions {
  secret: string;
  accessTtlSeconds: number;
}

const ALGORITHM = "HS256";

export function createTokenService({ secret, accessTtlSeconds }: TokenServiceOptions): TokenService {
  return {
    signAccessToken({ sub, username }) {
      return jwt.sign({ username }, secret, {
        algorithm: ALGORITHM,
        subject: sub,
        expiresIn: accessTtlSeconds,
      });
    },

    verifyAccessToken(token) {
      try {
        const decoded = jwt.verify(token, secret, { algorithms: [ALGORITHM] });
        if (typeof decoded === "string" || typeof decoded.sub !== "string" || typeof decoded.username !== "string") {
          throw new Error("payload inesperado");
        }
        return { sub: decoded.sub, username: decoded.username };
      } catch {
        throw new AppError(401, "UNAUTHORIZED", "Token de acceso inválido o expirado");
      }
    },

    generateRefreshToken() {
      return randomBytes(32).toString("base64url");
    },

    hashRefreshToken(token) {
      return createHash("sha256").update(token).digest("hex");
    },
  };
}
```

```ts
import { randomBytes } from "node:crypto";
import { Prisma, type PrismaClient } from "../generated/prisma/client.js";
import { AppError } from "../http/errors.js";
import type { PasswordHasher } from "./password.js";
import type { TokenService } from "./tokens.js";

export interface AuthUser {
  id: string;
  email: string;
  username: string;
  createdAt: Date;
}

export interface AuthResult {
  user: AuthUser;
  accessToken: string;
  refreshToken: string;
  refreshExpiresAt: Date;
}

export interface AuthServiceDeps {
  prisma: PrismaClient;
  hasher: PasswordHasher;
  tokens: TokenService;
  refreshTtlMs: number;
  /** Reloj inyectable para poder probar la expiración. */
  now?: () => Date;
}

const INVALID_REFRESH = () =>
  new AppError(401, "INVALID_REFRESH_TOKEN", "Sesión inválida o expirada. Inicia sesión de nuevo.");

function toAuthUser(user: { id: string; email: string; username: string; createdAt: Date }): AuthUser {
  return { id: user.id, email: user.email, username: user.username, createdAt: user.createdAt };
}

export class AuthService {
  private readonly prisma: PrismaClient;
  private readonly hasher: PasswordHasher;
  private readonly tokens: TokenService;
  private readonly refreshTtlMs: number;
  private readonly now: () => Date;
  /** Hash de relleno: se verifica cuando el email no existe para que login tarde igual. */
  private readonly dummyHash: Promise<string>;

  constructor(deps: AuthServiceDeps) {
    this.prisma = deps.prisma;
    this.hasher = deps.hasher;
    this.tokens = deps.tokens;
    this.refreshTtlMs = deps.refreshTtlMs;
    this.now = deps.now ?? (() => new Date());
    this.dummyHash = deps.hasher.hash(randomBytes(16).toString("hex"));
  }

  /** `email` debe llegar ya normalizado (minúsculas y sin espacios). */
  async register(input: { email: string; username: string; password: string }): Promise<AuthResult> {
    await this.assertAvailable(input.email, input.username);
    const passwordHash = await this.hasher.hash(input.password);

    let user;
    try {
      user = await this.prisma.user.create({
        data: { email: input.email, username: input.username, passwordHash },
      });
    } catch (error) {
      // Dos registros simultáneos pueden pasar la comprobación previa; la base de datos decide.
      if (error instanceof Prisma.PrismaClientKnownRequestError && error.code === "P2002") {
        await this.assertAvailable(input.email, input.username);
      }
      throw error;
    }
    return this.issueSession(this.prisma, user);
  }

  async login(input: { email: string; password: string }): Promise<AuthResult> {
    const user = await this.prisma.user.findUnique({ where: { email: input.email } });
    if (!user) {
      await this.hasher.verify(input.password, await this.dummyHash);
      throw new AppError(401, "INVALID_CREDENTIALS", "Email o contraseña incorrectos");
    }
    const ok = await this.hasher.verify(input.password, user.passwordHash);
    if (!ok) {
      throw new AppError(401, "INVALID_CREDENTIALS", "Email o contraseña incorrectos");
    }
    return this.issueSession(this.prisma, user);
  }

  /** Rota el refresh token: el usado queda revocado y se entrega uno nuevo. */
  async refresh(refreshToken: string): Promise<AuthResult> {
    const tokenHash = this.tokens.hashRefreshToken(refreshToken);
    const now = this.now();

    return this.prisma.$transaction(async (tx) => {
      const record = await tx.refreshToken.findUnique({ where: { tokenHash }, include: { user: true } });
      if (!record || record.revokedAt !== null || record.expiresAt <= now) {
        throw INVALID_REFRESH();
      }
      // La condición revokedAt = null hace que solo una petición concurrente gane.
      const revoked = await tx.refreshToken.updateMany({
        where: { id: record.id, revokedAt: null },
        data: { revokedAt: now },
      });
      if (revoked.count !== 1) {
        throw INVALID_REFRESH();
      }
      return this.issueSession(tx, record.user);
    });
  }

  /** Es idempotente: cerrar una sesión desconocida o ya cerrada no es un error. */
  async logout(refreshToken: string): Promise<void> {
    const tokenHash = this.tokens.hashRefreshToken(refreshToken);
    await this.prisma.refreshToken.updateMany({
      where: { tokenHash, revokedAt: null },
      data: { revokedAt: this.now() },
    });
  }

  async me(userId: string): Promise<AuthUser> {
    const user = await this.prisma.user.findUnique({ where: { id: userId } });
    if (!user) {
      throw new AppError(401, "UNAUTHORIZED", "El usuario ya no existe");
    }
    return toAuthUser(user);
  }

  private async assertAvailable(email: string, username: string): Promise<void> {
    const emailTaken = await this.prisma.user.findUnique({ where: { email }, select: { id: true } });
    if (emailTaken) {
      throw new AppError(409, "EMAIL_TAKEN", "Ese email ya está registrado");
    }
    const usernameTaken = await this.prisma.user.findFirst({
      where: { username: { equals: username, mode: "insensitive" } },
      select: { id: true },
    });
    if (usernameTaken) {
      throw new AppError(409, "USERNAME_TAKEN", "Ese nombre de usuario ya está en uso");
    }
  }

  private async issueSession(
    db: Prisma.TransactionClient | PrismaClient,
    user: { id: string; email: string; username: string; createdAt: Date },
  ): Promise<AuthResult> {
    const refreshToken = this.tokens.generateRefreshToken();
    const refreshExpiresAt = new Date(this.now().getTime() + this.refreshTtlMs);
    await db.refreshToken.create({
      data: {
        userId: user.id,
        tokenHash: this.tokens.hashRefreshToken(refreshToken),
        expiresAt: refreshExpiresAt,
      },
    });
    return {
      user: toAuthUser(user),
      accessToken: this.tokens.signAccessToken({ sub: user.id, username: user.username }),
      refreshToken,
      refreshExpiresAt,
    };
  }
}
```

```ts
import type { RequestHandler, Response } from "express";
import { AppError } from "../http/errors.js";
import type { AccessTokenPayload, TokenService } from "./tokens.js";

export interface AuthContext {
  userId: string;
  username: string;
}

/** Exige `Authorization: Bearer <accessToken>` y deja el usuario en `res.locals.auth`. */
export function createRequireAuth(tokens: TokenService): RequestHandler {
  return (req, res, next) => {
    const header = req.headers.authorization;
    const match = header ? /^Bearer (\S+)$/.exec(header) : null;
    if (!match?.[1]) {
      throw new AppError(401, "UNAUTHORIZED", "Falta el token de acceso");
    }
    const payload: AccessTokenPayload = tokens.verifyAccessToken(match[1]);
    res.locals.auth = { userId: payload.sub, username: payload.username } satisfies AuthContext;
    next();
  };
}

export function getAuth(res: Response): AuthContext {
  return res.locals.auth as AuthContext;
}
```

```ts
import { type CookieOptions, type Response, Router } from "express";
import type { Env } from "../config/env.js";
import { AppError } from "../http/errors.js";
import { createRequireAuth, getAuth } from "./auth.middleware.js";
import { loginSchema, registerSchema } from "./auth.schemas.js";
import type { AuthResult, AuthService, AuthUser } from "./auth.service.js";
import type { TokenService } from "./tokens.js";

export const REFRESH_COOKIE = "refresh_token";

export interface AuthRouterDeps {
  env: Env;
  authService: AuthService;
  tokens: TokenService;
}

function toUserDto(user: AuthUser) {
  return { id: user.id, email: user.email, username: user.username, createdAt: user.createdAt.toISOString() };
}

export function createAuthRouter({ env, authService, tokens }: AuthRouterDeps): Router {
  const router = Router();
  const requireAuth = createRequireAuth(tokens);

  // La cookie solo viaja a /auth: el resto de la API nunca la recibe.
  const cookieOptions: CookieOptions = {
    httpOnly: true,
    secure: env.COOKIE_SECURE,
    sameSite: env.COOKIE_SAME_SITE,
    path: "/auth",
  };

  function startSession(res: Response, result: AuthResult): void {
    res.cookie(REFRESH_COOKIE, result.refreshToken, { ...cookieOptions, expires: result.refreshExpiresAt });
  }

  function endSession(res: Response): void {
    res.clearCookie(REFRESH_COOKIE, cookieOptions);
  }

  router.post("/register", async (req, res) => {
    const input = registerSchema.parse(req.body);
    const result = await authService.register(input);
    startSession(res, result);
    res.status(201).json({ user: toUserDto(result.user), accessToken: result.accessToken });
  });

  router.post("/login", async (req, res) => {
    const input = loginSchema.parse(req.body);
    const result = await authService.login(input);
    startSession(res, result);
    res.json({ user: toUserDto(result.user), accessToken: result.accessToken });
  });

  router.post("/refresh", async (req, res) => {
    const token: unknown = req.cookies?.[REFRESH_COOKIE];
    if (typeof token !== "string" || token === "") {
      throw new AppError(401, "INVALID_REFRESH_TOKEN", "No hay una sesión activa");
    }
    try {
      const result = await authService.refresh(token);
      startSession(res, result);
      res.json({ user: toUserDto(result.user), accessToken: result.accessToken });
    } catch (error) {
      endSession(res);
      throw error;
    }
  });

  router.post("/logout", async (req, res) => {
    const token: unknown = req.cookies?.[REFRESH_COOKIE];
    if (typeof token === "string" && token !== "") {
      await authService.logout(token);
    }
    endSession(res);
    res.status(204).end();
  });

  router.get("/me", requireAuth, async (_req, res) => {
    const user = await authService.me(getAuth(res).userId);
    res.json({ user: toUserDto(user) });
  });

  return router;
}
```

```ts
import cookieParser from "cookie-parser";
import cors from "cors";
import express, { type Express } from "express";
import { createAuthRouter } from "./auth/auth.routes.js";
import { AuthService } from "./auth/auth.service.js";
import { createPasswordHasher } from "./auth/password.js";
import { createTokenService } from "./auth/tokens.js";
import type { Env } from "./config/env.js";
import type { PrismaClient } from "./db/prisma.js";
import { errorHandler, notFoundHandler } from "./http/errors.js";

export interface AppDeps {
  env: Env;
  prisma: PrismaClient;
}

export function createApp({ env, prisma }: AppDeps): Express {
  const tokens = createTokenService({
    secret: env.JWT_ACCESS_SECRET,
    accessTtlSeconds: env.ACCESS_TOKEN_TTL_SECONDS,
  });
  const authService = new AuthService({
    prisma,
    hasher: createPasswordHasher(env.BCRYPT_COST),
    tokens,
    refreshTtlMs: env.REFRESH_TOKEN_TTL_DAYS * 24 * 60 * 60 * 1000,
  });

  const app = express();
  app.disable("x-powered-by");
  app.use(cors({ origin: env.CORS_ORIGIN, credentials: true }));
  app.use(express.json({ limit: "10kb" }));
  app.use(cookieParser());

  app.get("/health", (_req, res) => {
    res.json({ status: "ok" });
  });
  app.use("/auth", createAuthRouter({ env, authService, tokens }));

  app.use(notFoundHandler);
  app.use(errorHandler);
  return app;
}
```
